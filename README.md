# CS2_Molave_Lopez

## Description

This program calculates the distance between two points using their X and Y coordinates.

## How to Run

1. Open the program.
2. Run the program.
3. Enter the required coordinate values.
4. View the calculated distance.

## Required Input

Enter the following values:

* **X1** – X coordinate of Point 1
* **Y1** – Y coordinate of Point 1
* **X2** – X coordinate of Point 2
* **Y2** – Y coordinate of Point 2
