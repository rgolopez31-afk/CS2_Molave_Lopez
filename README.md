# CS2_Molave_Lopez

## Description
This program calculates the distance between two coordinates.

## How to Run
1. Open the program.
2. Run the program.
3. Enter the required values.

## Input Needed
The values you have to enter are
- X1 (X coordinate for point 1)
- Y1 (Y coordinate for point 1)
- X2 (X coordinate for point 2)
- Y2 (Y coordinate for point 2)
